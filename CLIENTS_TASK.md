# 📋 ТЗ: Доработка модуля «Клиенты» (Clients)

> Цель: сделать полноценную CRM-базу клиентов с возможностью управления, просмотра статистики и истории их мероприятий. Соблюдать правила из `AGENTS.md`.

---

## 🎯 ЧТО ДЕЛАЕМ: ОБЗОР

1. **Типизация**: расширить интерфейс `Client` в `src/types/index.ts` (добавить поля для доп. контактов, заметок и общей статистики LTV).
2. **Интеграция**:
   - Перевести текущий `Clients.tsx` с `mockClients` на `useClients()`.
3. **Управление (CRUD)**:
   - Реализовать `ClientFormModal.tsx` для добавления и редактирования клиентов.
   - Реализовать удаление (с подтверждением).
4. **Детальный просмотр**:
   - Создать `ClientDetailsModal.tsx` (или отдельную страницу/слайдер), где видно:
     - Основную информацию (телефон, email, компания, заметки).
     - **Историю мероприятий** этого клиента (берётся из `useEvents()`).
     - **LTV (Lifetime Value)** — сумму всех успешно проведённых (`done`) мероприятий клиента.
5. **Поиск и сортировка**:
   - Поиск по имени, телефону, email, компании.
   - Сортировка по алфавиту, дате добавления, LTV.

---

## 🛠️ ПОШАГОВЫЙ ПЛАН РЕАЛИЗАЦИИ

### ШАГ 1: Расширение типов и контекста

1. **`src/types/index.ts`**:
```typescript
export interface Client {
  id: string
  name: string
  email?: string
  phone?: string
  company?: string
  notes?: string
  createdAt: string
  updatedAt: string
}
```
*(Убедиться, что старые обязательные поля, кроме name, стали опциональными, чтобы не ломать старые данные).*

2. **`src/context/ClientsContext.tsx`**:
   - Добавить `updateClient`, `removeClient` (если их ещё нет).

---

### ШАГ 2: Главная страница `Clients.tsx`

1. Заменить импорт моковых данных на вызов `const { clients } = useClients()`.
2. Добавить поисковую строку (по name, email, phone, company).
3. Добавить кнопку «Добавить клиента».

---

### ШАГ 3: Создание/Редактирование (`ClientFormModal.tsx`)

1. Создать форму для ввода `name` (обязательно), `phone`, `email`, `company`, `notes`.
2. Использовать `useClients()` для сохранения.
3. Добавлять запись в активность («Создан клиент...»).

---

### ШАГ 4: Детальная карточка клиента (`ClientDetailsModal.tsx`)

1. При клике на карточку клиента на главной странице — открывать детали.
2. В деталях:
   - Вывести данные клиента.
   - Использовать `useEvents()`: отфильтровать мероприятия по `clientId`.
   - Показать список мероприятий.
   - Рассчитать и показать LTV (сумма поля `value` у мероприятий со статусом `done`).

---

### ШАГ 5: Удаление

1. Кнопка удаления в карточке/деталях.
2. Использовать `@/components/ui/confirm-dialog`.
3. Запретить удаление (или предупреждать), если у клиента есть мероприятия.

- [ ] Поиск фильтрует список клиентов в реальном времени.
- [ ] `npm run tsc --noEmit`, `npm run build`, `npm run lint` проходят без ошибок.
