# 📋 ТЗ: Настройка Главной страницы (Dashboard)

> Цель: сделать дашборд аналитическим центром приложения, показывающим реальную сводку по бизнесу на основе данных из контекстов (Мероприятия, Клиенты, Активности). Соблюдать правила из `AGENTS.md`.

---

## 🎯 ЧТО ДЕЛАЕМ: ОБЗОР

1. **Интеграция**: убрать моковые данные (`mockActivities`, заглушки цифр) и подключить реальные контексты:
   - `useEvents()`
   - `useClients()`
   - `useCocktails()`
   - `useActivities()`
2. **Сводные виджеты (Метрики)**:
   - Всего мероприятий (всех статусов).
   - Выручка (сумма бюджетов мероприятий со статусом `done`).
   - Активные сделки (сумма бюджетов `new` + `in_progress` + `confirmed`).
   - Клиентов в базе.
3. **Ближайшие мероприятия**:
   - Вывод топ-3 или топ-5 мероприятий со статусом `confirmed`, отсортированных по дате (ближайшие).
4. **Топ коктейлей (опционально, если есть данные)**:
   - Найти самые часто используемые коктейли в подтверждённых/проведённых мероприятиях (если коктейли уже сохраняются в `details` мероприятий).
5. **Лента активности**:
   - Вывод реальных событий из `ActivitiesContext`.

---

## 🛠️ ПОШАГОВЫЙ ПЛАН РЕАЛИЗАЦИИ

### ШАГ 1: Подключение контекстов в `Dashboard.tsx`

```tsx
const { events } = useEvents()
const { clients } = useClients()
const { activities } = useActivities()
```

### ШАГ 2: Расчёт метрик (Виджеты)

Написать `useMemo` для расчёта показателей:
- `totalRevenue`: сумма `event.value` где `stage === "done"`.
- `pipelineValue`: сумма `event.value` где `stage` входит в `['new', 'in_progress', 'confirmed']`.
- `totalEvents`: `events.length`.
- `totalClients`: `clients.length`.

Обновить UI карточек-виджетов, подставив эти значения.

### ШАГ 3: Блок «Ближайшие мероприятия»

1. Отфильтровать `events`: `stage === "confirmed"`.
2. Отсортировать по дате (по возрастанию).
3. Взять первые 5 штук.
4. Вывести в виде списка или карточек (название, дата, заказчик). Сделать кликабельными (по возможности вести на страницу Events с открытием деталей, либо просто отображать инфо).

### ШАГ 4: Лента активности (Recent Activities)

1. Взять `activities` из `useActivities()`.
2. Отсортировать по `timestamp` по убыванию (свежие сверху).
3. Взять первые 10-15 штук.
4. Вывести в списке (тип события, описание, кто сделал, время в формате "Сегодня, 14:00" или "2 дня назад").

## 🔍 КРИТЕРИИ ГОТОВНОСТИ

- [ ] На дашборде больше нет захардкоженных цифр или импортов из `mockData`.
- [ ] При добавлении/изменении статуса мероприятия на странице Events — цифры выручки и воронки на дашборде обновляются автоматически.
- [ ] При совершении действий (добавление клиента, перемещение карточки Kanban) — они появляются в ленте активности.
- [ ] `npm run tsc --noEmit`, `npm run build`, `npm run lint` проходят без ошибок.
