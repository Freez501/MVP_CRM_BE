# 📋 ТЗ: Внедрение E2E-тестирования (Playwright)

> Цель: настроить автоматизированное тестирование интерфейса (E2E), чтобы робот мог самостоятельно открывать браузер, кликать по кнопкам, заполнять формы и проверять, что основной функционал CRM не сломан. Соблюдать правила из `AGENTS.md`.

---

## 🎯 ЧТО ДЕЛАЕМ: ОБЗОР

1. **Установка Playwright**: добавление зависимостей в проект.
2. **Настройка конфигурации**: создание `playwright.config.ts` (запуск локального dev-сервера перед тестами).
3. **Написание базовых тестов**:
   - Навигация по страницам (Дашборд, Клиенты, Мероприятия, Калькулятор).
   - Создание нового клиента через модальное окно.
   - Базовый Drag & Drop (или смена статуса) мероприятия на Kanban-доске.
4. **Обновление скриптов**: добавление команд в `package.json` для запуска тестов с UI и без.

---

## 🛠️ ПОШАГОВЫЙ ПЛАН РЕАЛИЗАЦИИ

### ШАГ 1: Установка зависимостей

Нужно установить `@playwright/test` в devDependencies.

### ШАГ 2: Создание `playwright.config.ts`

В корне проекта создать конфиг:
```typescript
import { defineConfig, devices } from '@playwright/test';

export default defineConfig({
  testDir: './e2e',
  fullyParallel: true,
  forbidOnly: !!process.env.CI,
  retries: process.env.CI ? 2 : 0,
  workers: process.env.CI ? 1 : undefined,
  reporter: 'html',
  use: {
    baseURL: 'http://localhost:5173',
    trace: 'on-first-retry',
  },
  projects: [
    {
      name: 'chromium',
      use: { ...devices['Desktop Chrome'] },
    },
  ],
  webServer: {
    command: 'npm run dev',
    url: 'http://localhost:5173',
    reuseExistingServer: !process.env.CI,
  },
});
```

### ШАГ 3: Написание тестов (Папка `e2e/`)

Создать папку `e2e` в корне проекта.

1. **`e2e/navigation.spec.ts`**:
   - Проверить, что открывается главная страница (Дашборд).
   - Проверить переходы по всем пунктам меню в сайдбаре (Клиенты, Мероприятия, Калькулятор, База).

2. **`e2e/clients.spec.ts`**:
   - Открыть страницу Клиенты.
   - Нажать кнопку "Добавить".
   - Заполнить форму (`name`, `phone`).
   - Нажать Сохранить.
   - Проверить, что клиент появился в списке.

3. **`e2e/events.spec.ts`**:
   - Открыть страницу Мероприятия.
   - Проверить наличие колонок (Новый, В работе и т.д.).
   - Попробовать найти конкретную карточку (или проверить, что они рендерятся).

### ШАГ 4: Скрипты в `package.json`

Добавить в раздел `scripts`:
```json
"test:e2e": "playwright test",
"test:e2e:ui": "playwright test --ui"
```

## 🔍 КРИТЕРИИ ГОТОВНОСТИ

- [ ] Playwright установлен и сконфигурирован.
- [ ] Папка `e2e` содержит минимум 3 тестовых файла.
- [ ] Запуск `npx playwright test` проходит успешно (или запускает скачивание браузеров, что нормально для первого запуска).
- [ ] Конфиг автоматически поднимает `npm run dev` перед прогоном тестов.
