# 🚀 Задача: Открытая регистрация (Self-Serve) и Paywall (Триал 7 дней)

## 📌 Контекст
Мы переходим на бизнес-модель автоматических продаж (Self-Serve SaaS). 
Теперь любой желающий может зайти на сайт, зарегистрироваться и получить свою пустую изолированную CRM. База данных автоматически создает для него компанию и выдает 7-дневный пробный период (trial).
Если 7 дней истекли, а подписка не оплачена, доступ к CRM блокируется красивым экраном Paywall.

## 🛠 Задачи для агента (IDE)

### Шаг 1: Обновление типов
В `src/types/index.ts` обнови интерфейс `Company`:
```ts
export interface Company {
  id: string;
  name: string;
  logoUrl?: string;
  defaultCurrency: string;
  status: "trial" | "active" | "blocked";
  trial_ends_at: string;
}
```

### Шаг 2: Переработка страницы регистрации (`/login` или `/register`)
1. Убери выбор роли (select "admin", "partner", "staff") из формы регистрации.
2. Добавь обязательное поле: **Название компании** (input).
3. При вызове `supabase.auth.signUp`, передавай это название в `user_metadata`:
   ```ts
   options: {
     data: {
       name: displayName,
       company_name: companyName, // Важно: именно company_name (его ждет SQL триггер)
     },
   }
   ```

### Шаг 3: Логика Paywall (Блокировка по истечении триала)
1. В `src/context/CompanyContext.tsx` убедись, что поля `status` и `trial_ends_at` парсятся и доступны.
2. Создай новый компонент/страницу `src/pages/Paywall.tsx`:
   - Красивый полноэкранный дизайн (используй стекло, размытие фона, можно добавить иконку замка `Lock`).
   - Текст: "Время пробного периода истекло. Ваш 7-дневный доступ к Brilliant CRM завершен. Чтобы продолжить работу и сохранить данные, пожалуйста, активируйте подписку."
   - Кнопка: "Связаться с администратором" (ссылка на Telegram, например `href="https://t.me/ваш_ник"`).
   - Кнопка "Выйти из аккаунта".
3. В `src/components/auth/ProtectedRoute.tsx` (или в `App.tsx` внутри `CompanyProvider`):
   - Добавь проверку: если пользователь авторизован, и `company.status === 'trial'`, проверь `company.trial_ends_at`.
   - Если текущая дата `new Date()` больше `new Date(company.trial_ends_at)`, то вместо запрошенной страницы принудительно рендери `<Paywall />` (или делай редирект на `/paywall`).

### Шаг 4: UI-индикатор триала (Опционально)
В сайдбаре (боковом меню) или в шапке (где-нибудь сбоку) выведи маленький красивый бейдж: "Триал: осталось X дней", если `status === 'trial'`. Это подстегнет клиентов к покупке!

## 🎨 Требования к коду
- Код должен быть надежным: триал не должен обходиться простым обновлением страницы.
- Эстетика Paywall должна соответствовать премиум-стилю CRM.
