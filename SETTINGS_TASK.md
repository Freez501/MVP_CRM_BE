# 🎯 Задача: Настройки, Профиль и Мультитенантность (SaaS)

## 📌 Контекст
Мы перевели базу данных (Supabase) на **мультитенантную SaaS-архитектуру**. 
- Теперь все основные таблицы (profiles, clients, events, cocktails и т.д.) имеют обязательное поле `company_id`.
- Изоляция данных работает на уровне RLS-политик Supabase: пользователи видят и редактируют данные только своей компании.
- База сама проставляет `company_id` при создании записей благодаря SQL-триггерам. Во Frontend CRUD-операциях добавлять `company_id` вручную **не нужно**.
- Роли: `admin` (полный доступ), `partner` (продажи/мероприятия), `staff` (производство/рецепты).

## 🛠 Задачи для агента (IDE)

### Шаг 1: Изучение архитектуры
Пожалуйста, перед написанием кода изучи:
1. Текущий UI-кит проекта в `src/components/ui/` (кнопки, инпуты, карточки, лоадеры). Мы используем Tailwind CSS, стекло (glassmorphism) и золотые акценты.
2. `src/types/index.ts` для понимания текущих типов.
3. `src/context/AuthContext.tsx` для понимания, как сейчас работает получение профиля.
4. `src/App.tsx` для просмотра роутов.

### Шаг 2: Обновление типов и Контекстов
1. В `src/types/index.ts` добавь тип `Company`:
   ```ts
   export interface Company {
     id: string;
     name: string;
     logoUrl?: string;
     defaultCurrency: string;
   }
   ```
2. В интерфейс `UserProfile` добавь опциональное поле `companyId?: string`.
3. В `AuthContext.tsx`:
   - Убедись, что метод `fetchProfile` корректно получает `company_id` из базы `profiles` и сохраняет его в стейт и localStorage (вместе с остальными полями).
4. Создай `src/context/CompanyContext.tsx`:
   - Должен запрашивать данные из таблицы `companies` (название, валюту, логотип), опираясь на `profile.companyId` из `AuthContext`.
   - Должен предоставлять метод `updateCompany(updates: Partial<Company>)` для сохранения изменений в Supabase.
   - Оберни `<App />` (или роуты) в `<CompanyProvider>`.

### Шаг 3: Страница "Мой профиль" (`/profile`)
- Доступна всем ролям.
- Раздели страницу на 2 блока (карточки):
  1. **Личные данные**: Имя, Телефон, Должность (вызов `updateProfile` из AuthContext).
  2. **Безопасность**: Смена пароля (используй `supabase.auth.updateUser({ password: newPassword })`).

### Шаг 4: Страница "Настройки" (`/settings`)
- Доступна `admin` и `partner`.
- Сделай навигацию табами (вкладками): "Компания" и "Справочники".
- **Таб "Компания"** (только если `role === 'admin'`):
  - Форма: Название компании (input), Базовая валюта (select: RUB, USD, EUR и т.д.).
  - Сохранение через `updateCompany` из CompanyContext.
- **Таб "Справочники"**:
  - Пока выведи красивую заглушку: иконка (lucide-react) и текст "Раздел в разработке. Здесь будет настройка статусов и категорий."

### Шаг 5: Страница "Команда" (`/team`)
- Доступна только `admin`.
- **Список команды**: Запроси из `profiles` всех пользователей, у которых `company_id` совпадает с текущим. Выведи в виде красивой таблицы или списка карточек (Имя, Email, Роль).
- **Кнопка "Пригласить сотрудника"**:
  - Открывает модальное окно.
  - Поля: Email (input), Роль (select: admin, partner, staff).
  - При отправке: делает `insert` в таблицу `invites`. (База сама проставит `company_id` и сгенерирует токен, тебе нужно отправить только `email` и `role`).

## 🎨 Требования к стилю кода
- Используй иконки из `lucide-react`.
- Придерживайся темной темы (цвета `bg-bg-app`, `bg-bg-panel`, золотой `text-brand`).
- Используй обертки `PageWrapper` для страниц.
- Обрабатывай состояния загрузки и ошибки (выводи тосты или alert-сообщения).
