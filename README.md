# MVP_CRM_BE · CocktailCalc Pro & CRM

Веб-приложение для расчёта технологических карт (ТТК), смет закупок коктейлей и полуфабрикатов, управления базой рецептов и мероприятий для выездного бара (Brilliant Bar Catering).

## 🚀 Стек технологий
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS
- **Иконки**: Lucide React
- **Экспорт**: html2canvas + jsPDF (умная разбивка на страницы А4 с отступами)

## 📦 Запуск проекта
```bash
npm install
npm run dev
```

## 🛠️ Сборка
```bash
npm run build
```
